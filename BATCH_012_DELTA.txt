PURPOSE:
  Add fragment and cut-quality screening to accepted BOSL2 occupied
  section records.

AUTHORITY:
  - exact normalized BOSL2 glyph region
  - exact clipped occupancy regions from Batch 011
  - deterministic automatic or manual grid
  - immutable diagnostic records
  - operator-configurable screening thresholds

QUALITY METRICS:
  - connected component count
  - component areas and bounds
  - smallest component area
  - minimum component bounding-box extent
  - minimum span-normalized area thickness estimate
  - shared seam lengths on left, right, bottom, and top
  - shared seam segment counts
  - shortest positive shared seam
  - multiple shared seam interval candidate
  - minimum flattened source-vertex distance to an internal cut
  - actual fragment bounds and configured-bed fit

REVIEW FLAGS:
  - multiple_components
  - small_component_area
  - thin_component_estimate
  - short_shared_seam
  - vertex_near_cut
  - counter_cut_candidate
  - bed_overflow

INTERPRETATION:
  - thresholds are screening controls, not automatic acceptance rules
  - effective thickness is an estimate:
      component area / maximum component bounding-box span
  - counter-cut candidate means an internal seam has multiple shared
    boundary intervals; it is not a definitive counter classification
  - vertex proximity uses captured flattened source vertices
  - no cut line is moved or rewritten
