PURPOSE:
  Normalize the source-specific uppercase A to an exact assembled height
  before rectangular sectioning.

NORMALIZATION METHODS:
  resize:
    Portable default. OpenSCAD resize() fits the actual rendered profile
    to the target height while preserving aspect ratio.
  manual:
    Uses explicit source-profile bounds measured at the configured probe
    size. Reports scale and final width numerically.
  textmetrics:
    Optional development-snapshot route using textmetrics(). Reports the
    resolved profile bounds, scale, and final width automatically.

FONT INVENTORY:
  - Reports OpenSCAD version and version number.
  - Reports Help > Font List as the complete machine-font-list location.
  - Reports the three configured source records.
  - Reports the bundled portable font families.
  - Optionally calls fontmetrics() for each configured source.
  - Does not claim that OpenSCAD scripts can enumerate every installed
    machine font.

SECTIONING:
  - Uppercase A only.
  - Grid is applied after normalization.
  - Exact target assembled height.
  - Whole normalized profile preview.
  - Normalized section plan.
  - Normalized exploded layout.
  - One normalized section at local print coordinates.
  - Console manifest for every configured cell.
  - No occupied-cell claim; empty intersections render nothing.

EXPLICITLY ABSENT:
  - connectors;
  - attachment methods;
  - inter-character spacing;
  - mounting;
  - automatic cut relocation;
  - sectioning of glyphs other than uppercase A.
