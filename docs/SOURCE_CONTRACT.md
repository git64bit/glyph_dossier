# Source contract

## Laboratory sources

Batch 002 provides exactly three mutable laboratory source identities:

```text
SRC_1
SRC_2
SRC_3
```

All comparison and observation workbenches use exact source lookup.

The initial font names are empty so that the batch compiles using the
same default-font behavior already validated in Batch 001. The user may
replace each empty name with an installed font family and style.

## Recommended source roles

The source IDs do not prescribe a specific licensed font. They may be
configured as:

- a plain sans-serif source;
- a serif source;
- a stencil or other contrasting font source.

A procedural stencil or segment generator will become a different
source kind in a later batch. Batch 002 source records are font-backed.

## Reproducibility threshold

A source is exploratory while its font name, license, URL, or revision
is unresolved. It may still be rendered and observed, but it should not
be treated as a reproducible accepted object source.
