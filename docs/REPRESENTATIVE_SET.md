# Representative study set

Batch 001 defines twenty primary characters:

```text
Uppercase:   A B O S Z
Lowercase:   a g i j m s
Digits:      0 1 2 4 8
Punctuation: ? ! : ;
```

## Coverage

- **A:** diagonals, counter, crossbar, acute apex.
- **B:** two counters and central waist.
- **O:** continuous ring.
- **S:** reversing curvature.
- **Z:** uninterrupted long diagonal.
- **a and g:** major font-form variation.
- **i and j:** disconnected dots; j adds a descender.
- **m:** repeated arches and narrow gaps.
- **s:** compact reversing curve.
- **0 and 1:** letter confusion and font variation.
- **2:** curve-to-diagonal-to-horizontal transition.
- **4:** open or closed form.
- **8:** two counters and narrow waist.
- **?, !, :, ;:** disconnected punctuation components.

This set is not a reduced alphabet. It is a diagnostic set used to
expose the major geometry classes before sectioning begins.
