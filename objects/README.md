# Accepted glyph objects

The catalog remains empty in Batch 004.

Batch 004 creates an exact-height uppercase-A sectioning route, not an
accepted glyph object.

Promotion requires:

1. an identified and reproducible font source;
2. a selected normalization method;
3. a confirmed assembled target height;
4. an acceptable normalized section plan;
5. successful export of occupied cells;
6. physical printing of the plain sections;
7. reconstruction of the larger A;
8. explicit acceptance.

Connectors and attachment methods remain outside this acceptance test.
